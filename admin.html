🌎 Firebase Integration Guide

1
Go to console.firebase.google.com and create a new project
2
Project Settings → Add Web App → Copy the firebaseConfig object
3
Enable Authentication: Email/Password provider (Google later)
4
Create Firestore Database in production mode
5
Paste config into js/firebase-config.js and add your admin email to ADMIN_EMAILS
6
Replace all MockAuth and MockUsers calls with Firebase equivalents in js/auth.js and js/admin.js
7
Deploy Firestore security rules from the firestore.rules file in your project
